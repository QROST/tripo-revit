## 已修复

| 优先级 | 问题与影响 | 改动及验证 |
| --- | --- | --- |
| P1 | 文档 session 按持久的 `CreationGUID` 分配，同源文件副本可能获得相同 session；切换文档的拒绝条件因而失效，关闭一份还会清除另一份的记录。 | 改为 `Document.Equals` 比较当前打开文档；关闭前捕获 session，成功关闭后只移除该记录。取消/失败关闭保留 session，新的 Closing 覆盖旧事件映射。覆盖副本、同文档不同包装对象、取消/失败关闭、关闭后失效 API、陈旧事件映射。 |
| P1 | 排队工作只在 Revit 实际执行时检查取消。宿主处于模态操作时，已超时的请求不能结束，且占住全部 4 个队列槽。 | 排队期间取消立即完成 Task；新请求清理已完成槽，保留 FIFO。状态原子区分排队/执行/结束，已开始事务仍返回真实结果。捕获 shutdown token 后再安排重试，避免关闭竞态访问已释放的取消源。 |
| P1 | IPv6 拒绝列表漏过 discard、benchmark、额外文档范围及未纳入普通公网使用的地址，和“仅公网下载”边界不一致。 | 与 Rhino 同步原生 IPv6 `2000::/3` 允许范围，排除 scope ID、`2001::/23`、两组文档范围及 6to4；保留 IPv4-mapped 的 IPv4 检查。新增 16 个边界用例。 |
| P2 | 任务状态读重试把服务端 `Retry-After` 截成最多 8 秒，长冷却期间仍提前请求。 | 尊重服务端冷却；超过当前读操作剩余预算时直接返回原错误，避免提前重试或超大延时溢出。新增长于本地 backoff 上限和超出总预算两个回归。 |
| P2 | 重新打包同版本会删除/覆盖现有候选与 ZIP，失败后原证据可能丢失；包内还遗漏项目 LICENSE/NOTICE。 | 同名候选拒绝覆盖、唯一临时目录、构建锁、无覆盖发布、仅清理自己产生的文件，加入许可证和 NOTICE；新增 PowerShell 合成回归并纳入 CI。拒绝空、重复或不支持的 Revit 年份列表。 |
| P2 | 当前 main 的 Windows CI 失败：发布策略测试硬编码 LF，Windows checkout 的 CRLF 使权限段断言失败。 | 断言前规范化换行，同时参数化覆盖 LF/CRLF。历史失败已从 [Actions 31341969863](https://github.com/QROST/tripo-revit/actions/runs/31341969863) 的实际错误日志确认；两个换行案例及版本一致性共 3 项定向测试通过。 |

文档身份选择依据 Autodesk 官方
[Document.Equals](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/f0efbd19-9399-1ee7-96e5-fe1dbbaa0815.htm)：
比较的是 Revit 会话里当前打开的同一文档，不是托管包装对象的引用相等。
IPv6 范围核对了 [IANA 特殊用途登记](https://www.iana.org/assignments/iana-ipv6-special-registry)。
这里对特殊用途 IPv6 服务采取比一般网络可路由性更严格的下载策略。

# 目录到 Revit 家具族

实现日期：2026-09-10。第一版采用人工复核后的产品资料包和固定网格家具族。
可离线执行目录解析与回归测试；生成和转换由现有 Tripo sidecar 完成。
真实 Revit 2025／2026 加载、窗口显示、族几何与 Undo 验收仍须在 Windows 宿主完成。

## 使用流程

1. 在 Revit 的 Tripo ribbon 打开 **Catalog Families**。先在原 Tripo 3D 窗口配置 API key。
2. **Add files** 添加 PDF、HTML 或 PNG/JPEG/WebP，可一次选多份资料；**Add public URL** 读取一个公开 HTTPS 产品页或 PDF。读取资料不会创建付费 Tripo 任务。
3. 检查产品候选。可合并多页、多文件资料，复制候选后拆分变体，移除无关图片，补充单产品图片，并调整生成顺序。原始文字框、页码、图片位置和摘要保存在资料包中。
4. 为每个产品选择 **一张**生成参考图，预览确认主体，填写名称、厂家、型号、描述及整体宽／深／高（mm）。座高、座深等不会自动替代整体尺寸。范围或冲突值必须人工选定。编辑字段后需要重新点击 **Apply fields & mark reviewed**。
5. 确认缩放方式：`uniform` 默认保持比例，任何轴与目标差异超过 10% 就拒绝该产品导入；`stretch` 是用户明确选择的逐轴拉伸。项目旋转在尺寸校准之后执行；它不能修复模型本身宽深轴颠倒。
6. 设置每件面数、材质、行宽与间距，点击 **Generate reviewed products**。窗口先冻结选定图片摘要与产品顺序，再展示本批具体产品、尺寸、模型及最多 `2 × 产品数` 次付费任务创建。只有确认后才上传选定图片并调用生成／转换。
7. 串行处理生成、轮询、OBJ 转换、导入。保存可读名称的 RFA，类别为 Furniture，族类型包含厂家、型号、描述、来源与名义尺寸；项目实例按旋转后的占地顺序排成行。几何以自身底面中心为原点，族文件不会带入整个批次的项目偏移。
8. **Pause** 停止新的步骤；**Resume batch** 选择保存的批次，使用原任务和导入编号。确认过的成功实例不会在恢复时重新插入。

尺寸是固定网格的资料参数，不是可驱动几何的原生参数化约束。整体比例匹配也不代表支腿、孔洞、扶手或材质细节达到制造商精度。

## 当前格式支持

| 输入或功能 | 第一版状态 |
| --- | --- |
| PDF | 提取文字及坐标、嵌入位图与 JPEG2000。按明确标题／SKU和图块候选整理，跨页归组须复核。保留无文字页并提示人工补充。 |
| HTML／产品 URL | 支持 JSON-LD Product/ProductGroup、可见规格表、部分图库与单位转换；按页面明确的规格标签关联变体，保留未知／冲突值。图片 URL 为候选，选中后才读取。 |
| 无 PDF 扩展名的 URL | 以返回内容识别 PDF；公共 HTTPS 跳转逐次校验。 |
| 多个本地文件 | 可逐份添加到同一资料包并手工合并。每次最多 30 文件。 |
| 产品系列／列表页 | 保留链接候选；需明确添加详情 URL，不自动遍历全站。 |
| PNG/JPEG/WebP | 可作独立输入或补充产品图。没有 OCR。 |
| 多图与文字 | 多图和文字保存在产品资料包；当前生成使用一个确认的主图。未实现多视图生成、以说明文字约束图像生成，或由场景照自动裁出单件家具。 |
| OCR／矢量尺寸图／扫描页 | 未实现完整页面渲染、OCR 和尺寸标注空间推理；需要原始照片／截图和人工尺寸。 |
| Issuu 等翻页器／需登录页面 | 不加载内嵌翻页器，不绕过登录；需可读取的 PDF 或独立详情页。 |
| ZIP／CSV／XLSX／官方 RFA 导入 | 未接入本目录流程，保留为后续适配。 |

当前默认上限为单输入 25 MiB、100 页、128 张图、100 个产品；一张图至多 25 MP／10 MB，累计抽图至多 64 MiB。超限会明确失败，不静默截断成“完整结果”。复核资料包最多 1000 候选；一个执行批次最多 100 产品。

## 保存与恢复

- 自动保存的 `catalog.json` 和抽出的图片位于本机 Tripo 数据目录下的 `catalogs/`。**Save catalog** 可另存 JSON；它引用本地图片路径，并不是包含全部媒体的便携压缩包。保留原图片目录。
- `catalog-batches/` 保存私有、带校验和的批次状态；单批固定产品顺序、尺寸、图片摘要、模型、付费 UUID、导入 UUID 与目标文档会话。保存不是授权，恢复仍需用户确认。
- 调用前保存派发记录，收到远端任务编号后即使取消也保存编号。对不确定的付费结果不创建新 UUID、不猜测重发；只有本地 journal 明确允许安全继续时才沿用同 UUID。
- 若族导入回执丢失，恢复只查询相同身份的既有实例。此查询不访问 Tripo，不依赖旧 OBJ 暂存。实例不存在时保持暂停，无法把 Undo／删除误当成需要补插。
- 批次固定在原先**保持打开的 Revit 文档会话**。切换文档会暂停；关闭并重新打开文档会产生新会话，当前不提供自动改绑。Revit 重启后的跨会话恢复、人工归档未完成批次仍需后续流程。
- 有未解决的批次记录时保留原有凭据保护，防止更换账号后把旧任务当作新任务处理。明确的尺寸／几何拒绝会记录为单产品失败，并继续其它产品；未知失败保持暂停。
- 如果 sidecar 重启丢失了临时 key，可选择 **Restore original session key**，为经过校验的未完成批次恢复原 key；只在当前会话使用。其它未完成工作仍阻止凭据变更，同一付费编号继续受账号指纹约束。
- 后续产品即使使用新的付费编号，也必须通过本批最早生成请求的账号指纹核验；核验与派发共享同一凭据锁。填错恢复 key 时拒绝新任务，不会在跳过已完成产品后改用另一个账号计费。
- RFA 保存于 `families/catalog-<attempt>/`，文件名含产品名称及完整导入编号，避免同名覆盖。源码和发布包不包含厂商 PDF／照片、API key 或真实生成结果。

## 不依赖 Revit 的解析工具

```sh
dotnet run --project src/Tripo.Catalog.Cli -- /path/to/catalog.pdf /path/to/new-output
dotnet run --project src/Tripo.Catalog.Cli -- https://example.com/product /path/to/new-output
```

输出目录必须为空或尚不存在。结果含 `catalog.json` 及可提取图片；CLI 不调用 Tripo，也不创建 Revit 族。离线调试可使用已保存的 HTML。

依赖固定为 [AngleSharp 1.7.3](https://www.nuget.org/packages/AngleSharp/1.7.3)、
[PdfPig 0.1.16](https://www.nuget.org/packages/PdfPig/0.1.16)、
[PdfPig JPEG2000 filter 0.1.16.1](https://www.nuget.org/packages/PdfPig.Filters.Jpx.OpenJpeg/0.1.16.1)。
JPEG2000 解码扩展为托管程序集。Revit 发布目录必须包含这些运行依赖及 [第三方许可](../THIRD-PARTY-NOTICES.md)。

## 已执行的真实来源检查

2026-09-10 使用 Release CLI 实测保留的官方资料，详细输入摘要见 [来源清单](./catalog-source-manifest.json)：

- Muuto Fiber Armchair Tube Base：1 个产品、4 个候选图片、5 项尺寸；整体高／宽／深为 770／545／560 mm，座高与座深均单独保留。
- Herman Miller Wireframe：50 个页面明确列出的 SKU 变体；每个保留 5 项规格。双人／三人款通过规格标签分别对应 1600.2／2266.95 mm 宽度，不把颜色和尺寸列任意组合。
- Herman Miller OE1：11 页提取 33 张图，形成 27 个待复核候选。第 10 页 19 图中，17 图与单品名称唯一配对；两个复合产品图保留待拆。OE1 Nook 按精确标题跨页合并。该手册不提供生成所需的完整尺寸，仍需规格来源或人工补充。抽查提取的 Rectangular Table 图片与产品图一致。

这些是解析和候选关联证据，不能替代真实 Tripo 生成或 Revit 族验收。

## 后续改进

优先推进真实 Revit 宿主验收、OCR／矢量尺寸图关联、图片裁切与产品确认体验、明确视角的多图生成、关闭项目后的可审核恢复和批次归档。之后扩展 ZIP／表格导入、目录翻页器与可驱动尺寸的参数化家具模板。厂商资料不足时应继续保留未知值，而不是生成看似精确的尺寸。
